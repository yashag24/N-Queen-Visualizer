# 👑 N-Queens Visualizer 🎭♟️  

## ✨ Welcome to N-Queen Visualizer with Backtracking! ✨  

An **interactive web application** that allows you to **visualize** the solution to the classic **N-Queens problem** using **HTML, JavaScript, CSS, and the Backtracking algorithm**. 🖥️📊  

---

## 🌟 Key Features  
✅ **🎨 Interactive Visual Representation:** Watch the N-Queens solution in real-time.  
✅ **📏 Customizable Chessboard Size:** Choose the board size (N) and observe how the queens are placed.  
✅ **🛠️ Step-by-Step Visualization:** The Backtracking algorithm solves the problem interactively.  
✅ **⚡ Adjustable Animation Speed:** Control the visualization speed as per your preference.  
✅ **📱 Responsive Design:** Works smoothly on **desktop & mobile** devices.  

---

## 🎮 How to Use?  
🔹 **🛠️ Select Chessboard Size (N):** Pick the board size from the interface.  
🔹 **▶️ Start Visualization:** Watch as queens get placed step-by-step.  
🔹 **⏩ Control Animation Speed:** Adjust the speed for a better experience.  

---

## 🛠️ Technologies Used  
- **📜 HTML:** Structure of the web page.  
- **🎨 CSS:** Beautiful and responsive styling.  
- **📌 JavaScript:** Implements the Backtracking algorithm & interactive features.  

---

## 🔍 How it Works?  
The **Backtracking algorithm** is used to solve the **N-Queens problem**, ensuring that no two queens attack each other. The solution process is **visualized step-by-step**, helping users understand how the algorithm **iterates and backtracks** to find valid queen placements. 👑🔄  

With this **N-Queen Visualizer**, you can **deepen your understanding** of algorithmic problem-solving in an **engaging and interactive** way. 🚀♟️
